# ECB validation example

This example uses daily PLN/EUR exchange rate data from the European Central Bank.

Series: `EXR.D.PLN.EUR.SP00.A`

Series page:
https://data.ecb.europa.eu/data/datasets/EXR/EXR.D.PLN.EUR.SP00.A

CSV API:
https://data-api.ecb.europa.eu/service/data/EXR/D.PLN.EUR.SP00.A?format=csvdata

The CSV file is not included in the repository.

Source: ECB statistics.
